# 🤝 Contributing Guidelines

Thank you for your interest in contributing!

Please follow these guidelines carefully.

---


# Step 1: Choose an Issue

Go to the **Issues** tab.

Select an issue that is not assigned.

Comment:

```text
I'd like to work on this issue.
```

Wait until the issue is assigned to you.

---

# Step 2: Fork the Repository

Fork this repository to your GitHub account.

---

# Step 3: Complete the Project

Build the complete project inside the assigned project folder.

---

# 📂 Required Folder Structure

```text
Project-XX-Project-Name/
│
├── README.md
├── .gitignore
├── project.ipynb
├── app.py
├── requirements.txt
```

---

# 📌 Project Requirements

Your project must:

- Be developed using Python
- Include a Streamlit frontend
- Include a Jupyter Notebook (`project.ipynb`)
- Include a `README.md`
- Include a `requirements.txt`
- Run without any errors

---

# 📖 README.md Should Include

- Project Overview
- Features
- Technologies Used
- Installation Steps
- How to Run
- Screenshots (Optional)

---

# 💻 Streamlit Application

The application should:

- Have a clean UI
- Accept user input
- Display output correctly
- Handle errors gracefully

---

# 🧹 Code Quality

Please ensure:

- Clean code
- Proper function names
- Meaningful variable names
- Comments where necessary
- No unnecessary files

---

# 🚀 Before Creating a Pull Request

Make sure:

- Project runs successfully
- All required files are included
- Code is tested
- README is complete

---

# 📝 Pull Request Title

Use this format:

```text
Completed Project-XX: Project Name
```

Example:

```text
Completed Project-03: Resume ATS Checker
```

---

# 📌 Pull Request Description

Include:

- Project Name
- Features Implemented
- Additional Improvements (if any)
- Screenshots (Optional)

---

# ❌ Do Not

- Submit incomplete projects
- Submit copied code without attribution
- Push directly to the main branch
- Remove or modify other project folders

---

# ❤️ Thank You

Thank you for contributing to this repository.

Happy Open Source! 🚀
