## 🎯 Objective

The purpose of this repository is to help beginners:

- Learn Git & GitHub
- Make their first Open Source Contribution
- Build real-world AI & ML projects
- Learn collaboration using Pull Requests

---

## 🚀 How to Contribute


1. Star this repository ⭐
2. Go to the **Issues** section.
3. Pick an issue you'd like to work on.
4. Comment:

```text
I'd like to work on this issue.
```

5. Wait until the issue is assigned.
6. Fork this repository.
7. Clone this repository.
8. Complete the project.
9. Create a Pull Request.

---

## 📁 Project Structure

Each project folder is initially empty.

After completing a project, it should contain:

```text
Project-XX-Project-Name/
│
├── README.md
├── .gitignore 
├── project.ipynb
├── app.py
├── requirements.txt
├── data/ # if data is present
```

---

## ✅ Mandatory Requirements

Every project **must** include:
- .gitignore
- README.md
- project.ipynb
- app.py
- requirements.txt
